GYM MANAGER - PHONE APP (Android and iPhone)
===========================================

HOST THE FOLDER (one time, free)
Option A - Netlify Drop (quickest, no account needed for a test):
  1. Open app.netlify.com/drop in Chrome or Safari.
  2. Drag the whole "gym-phone" folder onto the page.
  3. Copy the web address it gives you (https://....netlify.app).
  Note: an unclaimed Netlify Drop site expires after a while. Sign up free to keep it.
Option B - GitHub Pages (permanent, free, needs a GitHub account):
  Upload these files to a new public repository, then turn on Pages in Settings.

INSTALL ON THE PHONE
  Android (Chrome): open the address, tap the menu (three dots), tap "Install app" or "Add to Home screen".
  iPhone (Safari): open the address, tap Share, then "Add to Home Screen".

Works offline after the first visit. Data is stored on each phone separately until Google Drive sync is added.
